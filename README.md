# 🖥️ Python Tkinter Desktop Application

A desktop application developed using **Python** and **Tkinter** with a simple and user-friendly graphical interface.

## 📌 About the Project

This project is a desktop application developed in Python using the **Tkinter** library.

The main purpose of this application is to provide a simple graphical user interface (GUI) for performing the application's specific tasks without requiring command-line interaction.

The project was developed as a practical Python programming project and demonstrates the use of GUI development, event handling, functions, and user interaction in Python.

## ✨ Features

* 🖥️ User-friendly graphical interface
* 🐍 Developed with Python
* 🎨 GUI designed using Tkinter
* 🖱️ Event-driven programming
* 📋 User input and data processing
* ⚡ Simple and lightweight desktop application
## Run the application

```bash
python main.py
```
